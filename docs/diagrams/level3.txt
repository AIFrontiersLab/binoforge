Execution and recovery flow of MCP Operations Gateway. receive_request to discover_tools is control flow labeled request. discover_tools to validate_args is data flow labeled tool list. validate_args to policy_decision is control flow labeled arguments. policy_decision to execute_tool is control flow labeled permit. policy_decision to deny_request is control flow labeled deny. execute_tool to operation_store is state flow labeled operation. execute_tool to timeout_decision is control flow labeled reply. timeout_decision to reconcile_status is control flow labeled timeout. timeout_decision to verify_result is control flow labeled reply. reconcile_status to verify_result is data flow labeled completed. reconcile_status to escalate is control flow labeled still running. verify_result to write_audit is state flow labeled event. escalate to write_audit is state flow labeled escalation. deny_request to write_audit is state flow labeled denial.
