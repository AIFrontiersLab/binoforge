Component architecture of MCP Operations Gateway. CLI intake is proposed design. Accept the actor, tool, reason and idempotency key. MCP discovery is documented behavior. List tools from a local MCP server over stdio. Argument check is proposed design. Reject missing or oversized arguments. Identity policy is proposed design. Allow the tool only for a matching role. Approval gate is proposed design. Hold restart until an explicit approval flag is set. MCP executor is documented behavior. Call the selected tool with a timeout. Operation store is proposed design. Persist operation state before a delayed reply. Result check is proposed design. Confirm service generation and duplicate status. Recovery is proposed design. Poll status inside a bound and escalate if it stays running. Audit log is proposed design. Append permit, timeout, reconcile and escalation events.
